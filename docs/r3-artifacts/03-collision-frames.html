R3 §8.3 — Collision ledger (15 comparison frames)

Side-by-side pairs from the canonical ledger. Reviewer hesitation = rule or rendering fails. Channels stay separate: identity = notch + stroke texture; analysis = border/ring; ingest = center glyph. Spec: docs/r3-artifacts/03-collision-ledger.md

01 · Disabled vs Unknown

Both inert/desaturated. Separating rule: Disabled has no border. Unknown has a border. Silhouette, not color.

Merge
Disabled — 40% opacity, no border
Unknown — dashed 6/4 border + empty notch

02 · Unknown vs Processing

Both unresolved. Separating rule: Unknown is static. Processing animates (or is explicitly paused, with a pause bar).

Unknown — static
Processing — partial ring (anim)

03 · Processing vs Possible

Both carry partial information. Separating rule: Processing is a border state. Possible is a notch state. Different channel.

Processing — ring / border channel
Possible — dash 3/2 + half-fill notch

04 · Paused vs Failed

Both stopped mid-operation. Separating rule: Paused is symmetric. Failed has a gap + !.

Paused — symmetric arc + pause bar
Failed — gap + ! suffix

05 · Paused vs Unknown

Both are “waiting.” Separating rule: Paused is a ring. Unknown is a notch.

Paused — ring (analysis)
Unknown — dashed notch (identity)

06 · Failed (analysis) vs Missing (ingest)

Both mean “can't proceed.” Separating rule: Analysis failed = ring gap. Ingest missing = center glyph.

Failed (analysis) — ring gap + !
⚠
Missing (ingest) — center glyph

07 · Ignored vs Disabled

Both “not active.” Separating rule: Ignored 35% + no border; Disabled 40% + no border — nearly identical, so separate surfaces (grid vs controls).

Ignored — 35%, no border · grid surface
Split
Disabled — 40%, no border · control surface

08 · Ruled out vs Unknown

Both “no identity.” Separating rule: Unknown is dashed. Ruled out is dashed + ≠. The mark is mandatory (suffix, not the state).

≠
Ruled out — dash 6/4 + empty notch + ≠
Unknown — dash 6/4, no mark

09 · Ruled out vs Possible

Both are dashed. Separating rule: Possible is dash 3/2 with half-fill notch. Ruled out is dash 6/4 with empty notch + ≠.

≠
Ruled out — 6/4 + empty + ≠
Possible — 3/2 + half-fill

10 · Confirmed vs Selected

Both are strong. Separating rule: Confirmed is a notch. Selected is an inset rule. Never the same channel.

Confirmed — solid notch (identity)
Selected — inset rule (selection)

11 · Stale vs Unknown

Both “not fresh.” Separating rule: Stale is a dotted ring. Unknown is a dashed notch.

Stale — dotted ring (analysis)
Unknown — dashed notch (identity)

12 · Destructive-armed vs Error

Both use red. Separating rule: Destructive red on the target object. Error red as a glyph — never a border, never on a button.

Destructive-armed — red on object
⚠ Can't decode HEVC
Error — red glyph only

13 · Primary vs Selected

Both high-contrast. Separating rule: Primary is an inverted pill (shape). Selected is a fill + rule (container). Different silhouettes.

Name
Primary — inverted pill
Library
Selected — fill + left rule

14 · Possible vs Stale

Both “mid” states. Separating rule: Different channels — notch vs border.

Possible — notch channel
Stale — border / ring channel

15 · Mixed identity (solid + ≠) vs Ruled out (dashed + ≠)

Both carry ≠. Separating rule: Mixed is solid. Ruled out is dashed. The ≠ is a suffix, not the state.

≠
Mixed — solid + ≠ suffix
≠
Ruled out — dashed 6/4 + ≠ suffix
