R3 §8.4 — State-triple grid (30 cards)

Every card exposes three channels: ingest (row) × analysis (column) × identity notch (cycles Unknown → Possible → Confirmed → Ruled out → Ignored across the 30 cells). Confusable pair = wrong channel assignment. Spec: docs/R3-BRIEF.md §7–§8.4.

Ingest (5): queued · running · paused · completed · cancelled Analysis (6): none · queued · detecting · embedding · clustered · failed Identity (cycles): U · P · C · R · I
